## Featured Projects

### 🤖 Discord Interactive Bot

A modular Discord bot built with **Python and discord.py**, using Cogs, Slash Commands, interactive components, environment variables and automated module loading. The project evolved into AI integration with **Google Gemini**, message processing and service separation.

**Learning:** Python, async programming, Discord APIs, modular architecture, Cogs, environment configuration and AI integration.

[![Discord Bot](https://img.shields.io/badge/View%20Project-Discord%20Bot-5865F2?style=for-the-badge&logo=discord&logoColor=white)](https://github.com/D13G0-O11VEIRA/Discord-interactive-bot)

### ♻️ ReFaxion AI

A web platform that combines **circular fashion and Artificial Intelligence**. Users can analyze clothing images with Gemini, receive outfit and reuse suggestions, and share results through a community feed.

**Learning:** HTML, CSS, JavaScript, Python, APIs, Gemini AI, authentication concepts, LocalStorage and responsive interfaces.

[![ReFaxion AI](https://img.shields.io/badge/View%20Project-ReFaxion%20AI-8E75B2?style=for-the-badge&logo=google&logoColor=white)](https://github.com/D13G0-O11VEIRA/ReFaxion-AI)

### 💱 Currency Converter

A Python desktop application built with **Tkinter** and a currency exchange API, including real-time conversion, currency inversion and connection-error handling.

**Learning:** Python, GUI development, HTTP/API consumption, error handling and application structure.

[![Currency Converter](https://img.shields.io/badge/View%20Project-Currency%20Converter-3776AB?style=for-the-badge&logo=python&logoColor=white)](https://github.com/D13G0-O11VEIRA/Conversor-de-moedas)

### ⚡ Electronic Projects

A collection of Arduino/C++ experiments involving **ultrasonic sensors, LCD displays, buttons, LEDs, seven-segment displays, potentiometers, PWM and motor control**.

The projects are helping me connect programming concepts with electronics, physical inputs/outputs and real-world control systems.

[![Electronic Projects](https://img.shields.io/badge/View%20Project-Electronic%20Projects-00979D?style=for-the-badge&logo=arduino&logoColor=white)](https://github.com/D13G0-O11VEIRA/Eletronic-projects)
